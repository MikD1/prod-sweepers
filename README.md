# PROD Sweepers

Однопользовательская пиксельная игра для браузера с клавиатурой и мышью. Лотти очищает открытый мир PROD от слоя багов, сдаёт их на станцию контроля качества и развивает свою уборочную службу.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Открыть адрес, который напечатает Vite (обычно http://localhost:5173).

```sh
npm run build       # проверка TypeScript и статическая сборка в dist/
npm run preview     # запуск собранной версии
npm test            # тесты симуляции и сохранений
npm run test:e2e    # браузерные сценарии Chromium
npm run balance     # воспроизводимая модель темпа экономики
```

Для e2e нужен Chromium Playwright. Если он ещё не установлен: `npx playwright install chromium`.

## Статическая сборка и публикация

`npm run build` создаёт готовую игру в `dist/`: HTML, CSS, JavaScript, Worker генерации мира и иконку. Папку можно целиком разместить на статическом хостинге. Относительная база `./` в `vite.config.ts` поддерживает и корень домена, и подпапку `/prod-sweepers/`. Для локальной проверки сборки: `npm run preview`. Открывать нужно HTTP-адрес, а не `index.html` через `file://`, поскольку генерация развитого мира использует Worker.

Для [репозитория игры](https://github.com/MikD1/prod-sweepers) добавлен workflow [pages.yml](.github/workflows/pages.yml). В **Settings → Pages → Build and deployment → Source** нужно один раз выбрать **GitHub Actions**. Каждый push в `main` запускает установку зависимостей, тесты, сборку и публикацию `dist/`; workflow также можно запустить вручную через вкладку Actions. Страница игры после успешного развёртывания: **https://mikd1.github.io/prod-sweepers/**.

Игра работает в браузере без backend и учётной записи. Прогресс хранится локально в браузере отдельно для каждого домена и устройства.

## Управление

| Действие | Клавиши |
| --- | --- |
| Идти | WASD / стрелки |
| Убирать перед собой | Удерживать пробел |
| Убирать в направлении курсора | Удерживать левую кнопку мыши |
| Сдать баги в приёмник / терминал; открыть магазин рядом | E |
| Живая карта мира и статистика (без паузы) | Tab |
| Состояние и содержимое постройки | Клик по постройке вне строительства |
| Магазин рядом: щётки / гараж; у терминала — склад и возврат | M / кнопка внизу |
| Текущее задание | Кнопка i слева сверху |
| Выбрать купленную щётку | 1–4 |
| Сесть в машину рядом с ней / выйти | V |
| Машина: вперёд / назад, руль | W / S, A / D |
| Строительство | B |
| Карта производственных цепочек | C / кнопка сверху / из строительства |
| Построить выбранный объект / разобрать | Левая кнопка мыши |
| Пауза / закрыть окно или строительство | Esc |
| Справка | ? / кнопка вверху |

Карта по Tab продолжает симуляцию: роботы двигаются, фабрики работают, время и показатели обновляются. Управление Лотти за картой заблокировано. Tab возвращает в мир, Esc из карты ставит игру на паузу. Мастерская, справка, карта цепочек и меню останавливают симуляцию. Подсказка задания скрыта по умолчанию за кнопкой i; открытие строительства сворачивает её. При смене вкладки игра ставится на паузу. Автосохранение каждые пять игровых секунд, при покупках, паузе и уходе со страницы. Мир продолжает жить только при открытой активной игре. Новый мир заменяет сохранение после подтверждения.

На стартовом экране есть кнопка **«Начать с развитой базой»**. Она запускает ускоренное прохождение нового мира с нуля в отдельном Web Worker: автопилот собирает баги настоящими щётками и машинами, отвозит сырьё и покупает улучшения на заработанные деньги. Две ранние фабрики остаются на базе; дополнительно строится промышленный блок из четырёх параллельных веток, на каждой свой анализатор и тестовый стенд. Общая сырьевая магистраль связывает его с двумя удалёнными приёмниками примерно в 1560 и 1385 пикселях от центра. Готовая продукция идёт отдельными маршрутами к четырём терминалам. Между постройками стоят конвейеры; развилки и повороты учитывают препятствия. После покупки полного флота автопилот разгружает контейнер, паркует машину и возвращает Лотти пешком на стартовую площадку обычными игровыми действиями. Всего в мире шесть анализаторов, шесть стендов, четыре приёмника, два малых робота и три PRO. Все пять помощников куплены на заработанные кредиты с учётом наценки за повторные покупки; оба типа продолжают работу после передачи мира игроку. Процент уборки, запасы фабрики, капсулы, положение машин и форма очищенных участков остаются такими, какими получились в прохождении; заранее нарисованного чистого круга и выданных ресурсов нет.

Во время подготовки видны игровое время, текущий этап и примерный прогресс. Браузер остаётся отзывчивым; подготовку можно отменить. Существующий мир и его сохранение заменяются только после успешного завершения. При ошибке можно повторить попытку; незавершённый результат не сохраняется. Получившийся мир использует обычное сохранение, Лотти начинает пешком с пустым рюкзаком, машины припаркованы, а роботы и производство продолжают работу.

## Что есть в игре

- Открытая карта 5376 × 4032: 16 районов, 36 мест для исследования с бонусами за открытие. Площадь увеличена на 36%, в удалённых районах слой багов плотнее. Основной вид отдалён: объекты на 20% меньше, видимая область шире.
- Слой багов с несколькими уровнями плотности. Уборка проявляет чистую поверхность; прогресс считается по реально собранным багам.
- Зубная, ручная, большая и турбощётка, каждая с большим контейнером: 120 / 300 / 600 / 1000 багов. Три улучшения вместимости и два улучшения скорости.
- Две машины: ранний мини-уборщик (1200 багов, до 55 багов/с) и тяжёлая уборочная машина (5000 багов, до 110 багов/с). Улучшения контейнеров действуют на обе. Щётки работают узкой прямоугольной полосой перед машиной: ширина 40 / 64 пикселя. Скорость в пути 145 / 180, при уборке 80 / 95 пикселей/с, задний ход — 45% скорости. Есть разгон, торможение и ограниченная скорость поворота; поворот на месте невозможен. Курсор не меняет направление щёток. Машины стоят рядом с гаражом; V выбирает ближайшую, обе сохраняют своё положение. При превышении вместимости пешего рюкзака нужно сначала разгрузиться.
- До пяти роботов, которые ищут сырьё по всей карте. Ранний пылесос (до 18 багов/с, контейнер 180) физически возит сырьё к ближайшему доступному приёмнику. Лоттик PRO (до 60 багов/с, контейнер 1200) отправляет добычу в подключённые приёмники без обратных рейсов и распределяет её по свободному месту. Его скорость снижена втрое. Полные и отключённые приёмники останавливают добычу, груз сохраняется. Дальние магистрали сокращают рейсы обычных роботов; дополнительные параллельные цепочки перерабатывают растущий поток от PRO.
- Две физические торговые станции: мастерская щёток (2592 / 2028) продаёт щётки, вместимость и скорость; гараж (2808 / 2028) — машины и роботов. Покупки доступны в радиусе 64, проверка действует и в движке. Вдали от базы можно открывать только строительство и информационные окна.
- Фабрика качества: приёмники, автоматические конвейеры, анализаторы и тестовые стенды. Капсулы действительно перемещаются по соединённым участкам; разрыв останавливает доставку без потери груза. Соединения с соседними элементами появляются автоматически с любой стороны.
- Центральная база 528 × 528 с четырьмя терминалами продажи по углам: сырые баги стоят 1 кредит, отчёты — 3, автотесты — 7 за единицу. Анализаторы перерабатывают сырьё, а деньги приходят после доставки продукции в терминал.
- Подсказки, задания, эффекты, фоновая 8-битная мелодия, сохранение мира и завершение полной уборки с возможностью остаться в мире. Кнопка звука отключает музыку и эффекты; в меню и на паузе музыка тоже отдыхает.

В новом мире база находится в центре карты: мастерская и гараж в середине, четыре защищённых терминала по углам. В каждую сторону можно строить независимую производственную линию. Бесплатных конвейеров и переработки нет. Любую постройку фабрики, включая загруженную и старую стартовую, можно разобрать. За купленную возвращается половина цены, за бесплатную стартовую — 0. Входной буфер, готовая продукция, груз капсул на удалённой клетке и материал незавершённой обработки сохраняются на складе терминала. Тип материала сохраняется; незавершённая обработка возвращает входное сырьё. Продать склад можно клавишей E у терминала или в окне терминала на базе (M). Все четыре терминала остаются частью базы; склад и возврат сырья доступны у любого из них. Все участки доступны сразу, обязательного таймера нет.

## Производство и логистика

| Объект | Цена | Работа |
| --- | --- | --- |
| Приёмник | 100 | Запас 4096 / 8192 / 16384 / 32768 вместе с уровнем контейнеров; при запасе от 32 отправляет по 32, меньшие грузы — по 8 или остатком |
| Конвейер | 10 | Соединяется со всех четырёх сторон, повороты и развилки появляются автоматически |
| Анализатор | 600 | До 8 багов → столько же отчётов за 0,2 секунды |
| Тестовый стенд | 3 600 | До 8 отчётов → столько же автотестов за 0,4 секунды |
| Терминал продажи | Уже на базе | Покупает сырьё и продукцию; строить новые терминалы нельзя |

Для первого дохода достаточно вручную сдать баги в терминал. Сам конвейер цену не повышает: линия без анализатора тоже продаёт баги по 1 кредиту. Анализатор доступен после ручной щётки; первая линия из приёмника, анализатора и одного конвейера стоит 710 кредитов. Карта цепочек (C) показывает все способы доставки и переработки, цену построек, доход за партию и схему размещения у базы. Фабрика позволяет получить больше с того же ресурса:

```text
Приёмник → конвейеры → анализатор → конвейеры → терминал
  8 багов                 8 отчётов              24 кредита

Приёмник → анализатор → тестовый стенд → терминал
  8 багов    8 отчётов       8 автотестов    56 кредитов
```

Машины имеют отдельные входной и выходной буферы по 32 единицы. Обработка занимает время; когда выход переполнен, производство ждёт. Дополнительные машины позволяют обрабатывать потоки параллельно. Повторная обработка уже готового материала в той же машине не увеличивает его цену: анализатор принимает только баги, стенд — только отчёты.

Если собственная выходная капсула стоит без движения, машина может дополнить её готовым запасом до 32 единиц. Это освобождает выходной буфер и позволяет продолжить обработку при общем входном и выходном участке ленты. Материал сохраняется; обычная отправка начинается с партий по восемь.

Одна сырьевая магистраль может разветвляться на четыре полные цепочки «анализатор → стенд». Крупные капсулы приёмника питают несколько машин; партии обработки остаются по восемь. Готовую продукцию лучше выводить отдельными лентами к свободным портам терминалов: объединение всех выходов снова создаёт узкое место. При слабой добыче дополнительные ветки простаивают; их смысл — перерабатывать растущие очереди от машин и PRO. Эта схема показана в справке по цепочкам (C) и используется в развитом старте.

Все элементы соединяются автоматически с четырёх сторон; ориентация не ограничивает маршруты. Несколько подходящих выходов получают капсулы по очереди. Полные выходы пропускаются без потери груза. Анализатор принимает только баги, стенд — отчёты, терминал — любой готовый материал. Конвейеры не отправляют капсулу обратно в сторону, откуда она только что пришла.

Приёмник рядом с местом уборки сокращает обратные рейсы. Соедини его с фабрикой и проложи маршрут готовой продукции до базы. Робот выбирает ближайший по проходимому пути приёмник со свободным местом и корректной цепочкой до терминала. Разрыв или несовместимый материал исключают маршрут; замкнутые участки проверяются без зацикливания поиска. Если доступных приёмников нет, он ждёт с грузом; напрямую кредиты не начисляет. Временная очередь внутри исправной линии не отменяет её маршрут. При частичной разгрузке остаток остаётся в контейнере. Перестройка маршрутов и пауза сохраняют содержимое капсул, машин и склада.

Возле постройки появляется только короткая подсказка действия. Кликни по ней вне режима строительства, чтобы открыть карточку состояния, запасов и обработки; повторный клик или кнопка закрытия скрывает карточку. При строительстве подпись внизу показывает причину красной клетки до клика: занятая постройка, расстояние, препятствие или недостающие кредиты. Конвейер ставится на свободные соседние клетки, а не поверх машины; соединения с соседними элементами образуются автоматически; приёмники и машины можно подключать с любой стороны. В обзоре по Tab — живая карта с базой, Лотти, движущимися роботами и открытыми местами мира; неизвестные места скрыты, подписи не перекрываются. Рядом шесть крупных показателей за всё время: время игры, процент очистки, число собранных багов, созданных отчётов и автотестов, общий заработок. Текущий баланс, снаряжение, контейнер, цены продукции и состояние отдельных машин доступны в основном интерфейсе. На основном экране панели производства нет. В маленьком окне цены доступны в меню строительства.

Сохранения используют формат v5. Старые миры v1–v4 сбрасываются: перенос прежней базы и прогресса отключён. При загрузке проверяются четыре защищённых терминала, состояние техники и содержимое фабрики.

## Экономика и развитие

| Покупка | Цена, кр. | Условие открытия |
| --- | ---: | --- |
| Ручная щётка | 400 | Сразу |
| Большая щётка | 1 800 | Ручная щётка |
| Турбощётка | 6 000 | Большая щётка |
| Контейнеры I / II / III | 300 / 1 200 / 4 200 | I сразу; II — большая щётка; III — турбощётка |
| Быстрые лапки I / II | 350 / 1 800 | I сразу; II — большая щётка |
| Анализатор | 600 | Ручная щётка |
| Тестовый стенд | 3 600 | Продано 64 отчёта или автотеста |
| Робот-пылесос | от 1 800 | Ручная щётка, продано 16 отчётов/автотестов, подключённый приёмник |
| Мини-уборщик | 2 200 | Ручная щётка, контейнеры I, продано 32 отчёта/автотеста |
| Уборочная машина | 12 000 | Большая щётка, контейнеры II, продано 128 автотестов |
| Лоттик PRO | от 75 000 | Тяжёлая машина, продано 256 автотестов |

Условия и текущий прогресс видны в соответствующем магазине и строительстве. Повторная покупка робота одного типа дороже на 20%, с округлением до сотен; первая покупка другого типа сохраняет базовую цену. Максимум пять помощников. Если все места заняты, покупка PRO улучшает одного обычного робота за полную цену, сохраняя его ID, позицию, груз и состояние. Флот из пяти обычных роботов не закрывает позднее развитие. Вместимость рюкзака определяется лучшей купленной щёткой, даже если взять старый инструмент. Каждое улучшение вместимости добавляет 50% её базового объёма: множители 1 / 1,5 / 2 / 2,5. Например, ручная щётка даёт 300 / 450 / 600 / 750, турбощётка — 1000 / 1500 / 2000 / 2500. Для мини-уборщика это 1200 / 1800 / 2400 / 3000, для тяжёлой машины — 5000 / 7500 / 10000 / 12500. Запас каждого приёмника удваивается с уровнем улучшения.

У терминала через его собственное окно (M) можно вернуть ранее проданные сырые баги по 2 кредита за штуку, партиями до 64, с учётом денег и свободного места. Запас конечен: проданное сырьё минус уже возвращённое. Отчёты и автотесты выкупать нельзя. Это позволяет освоить переработку даже после продажи всего сырья. Повторная продажа сырья по 1 кредиту убыточна; выкуп не создаёт новые баги и не меняет процент уборки.

Для сравнения стратегий: `npm run balance -- --mode=progression --parallel=2 --layout=network --seed=42 --json`. Точный сценарий кнопки развитого старта: `npm run balance -- --mode=developed --seed=42 --json`. Скрипт использует настоящий движок: движение с препятствиями, слои багов, вместимость, рейсы, покупки, очереди производства и продажи. Проверяет сохранение материала и полный денежный журнал, включая возврат сырья и разборку. Отдельные замеры производственного потолка и робота используют явно обозначенные профинансированные стартовые состояния; основной прогон начинается с нового мира без кредитов.

Сценарий и построение линий общие для кнопки развитого старта и проверки экономики: `src/game/autoplay.ts`. Автопилот использует точное знание сырья и не тратит время на меню; его игровое время описывает конкретную стратегию, а не обещает длительность человеческого прохождения. На seed 42 развитый старт покупает малого робота на 3,6-й игровой минуте, мини-уборщик — на 4,3-й, тяжёлую машину — на 11,3-й, первого PRO — на 17,1-й, второго — на 20,0-й, третьего — на 22,1-й. Второй малый робот куплен сразу после первого PRO. Передача мира после разгрузки и парковки происходит на 22,29-й минуте: очищено около 13%, потрачено 329 480 кредитов. В эту сумму входят реальные постройки и весь смешанный флот за 277 000; все личные улучшения к этому моменту ещё не куплены. Срок зависит от сгенерированных препятствий и сырья.

Большие приёмники позволяют разгрузить машину целиком, но не заменяют пропускную способность линии: заполненный выход останавливает поток. Один стенд перерабатывает до 20 единиц/с, тогда как PRO собирает до 60, поэтому его отдача зависит от числа параллельных цепочек. Приёмник в дальнем районе сокращает физические рейсы малого робота; PRO не нуждается в покрытии карты кругами приёмников. Четыре терминала дают дополнительные независимые порты продажи.

`npm run balance -- --mode=network --json` сравнивает один и тот же приёмник и общую магистраль с одной, двумя и четырьмя ветками. Оборудование финансируется и сырьё подаётся явно только в этом стендовом замере; время добычи и поездок исключено. После 300 секунд заполнения сети измеряются следующие 600 секунд с шагом 0,05 с. Результат для дальней магистрали, автотестов в секунду:

| Подача багов/с | 1 ветка | 2 ветки | 4 ветки |
| --- | ---: | ---: | ---: |
| 24 | 18,83 | 23,99 | 23,99 |
| 60 | 18,81 | 37,64 | 59,96 |
| 120 | 18,83 | 37,65 | 75,29 |

Стоимость таких сетей с одним приёмником: 5220 / 9780 / 18 530 кредитов. При подаче 60 багов/с расширение с двух до четырёх веток даёт примерно +9374 кредита валового дохода в минуту; при 24 багов/с это расширение ничего не даёт. Дополнительные 8750 кредитов возвращаются за 74 секунды в стендовом сценарии с подачей 60/с, с учётом запуска лент, но без добычи и поездок. Это оценка загрузки производства, а не обещание игроку такой же окупаемости. Цены оборудования сохранены: расширение окупается при достаточной добыче, а её рост требует дорогих машин и роботов.

Дополнительные 50 клеток конвейера стоят 500 кредитов и добавляют около 10 секунд до первой продажи; при постоянном большом запасе сырья установившийся поток сохраняется. Материал и деньги проверяются во всех 24 сочетаниях длины, числа веток и подачи. Отдельная конечная партия из 600 багов во всех шести конфигурациях даёт ровно 600 автотестов и 4200 кредитов: разветвления увеличивают скорость, количество материала сохраняется.

В мире seed 42 — 556 649 багов, то есть до 3 896 543 кредитов при полной переработке в автотесты. Все щётки и личные улучшения, обе машины, один малый робот и первый PRO стоят 107 050. Полный флот из пяти PRO вместе с техникой и личными улучшениями стоит 588 350 без построек. Повторные PRO стоят 75 000 / 90 000 / 108 000 / 129 600 / 155 500. Ресурсов достаточно для расширения, но одних приёмников для роста заработка недостаточно: нужны выходы конвейера и переработка.

## Устройство

TypeScript, Vite, Canvas 2D. Без игрового сервера, регистрации, сторонних запросов во время игры и внешних графических зависимостей. Пиксельная графика рисуется кодом.

- `src/game/world.ts` — генерация 16 районов, проходимая сетка и независимые копии мира.
- `src/game/autoplay.ts` — общий автопилот и стратегия развития для ускоренного старта и замеров экономики.
- `src/game/starts.ts` — запуск реального прохождения до промышленной сети и полного флота из двух малых роботов и трёх PRO, проверка сохранности ресурсов.
- `src/game/generation.ts` / `generation.worker.ts` — фоновая подготовка с прогрессом, отменой и обработкой ошибок.
- `src/game/engine.ts` — движение, уборка, экономика, локальные покупки, две машины, флот роботов, поиск пути и доставка капсул.
- `src/game/renderer.ts` — мир, спрайты, частицы, предпросмотр строительства и мини-карта.
- `src/game/persistence.ts` — сериализация и проверка сохранений.
- `src/game/overview.ts` — обзор по Tab с большой картой и шестью основными показателями за всё время.
- `src/game/production-guide.ts` — карта способов продажи, производственных цепочек и первая схема сборки; цены и рецепты берутся из конфигурации игры.
- `src/game/music.ts` — оригинальная зацикленная мелодия, синтезированная в браузере: пульсовый голос, арпеджио и треугольный бас.
- `src/main.ts` — браузерное управление, интерфейс, звук и игровой цикл.
- `e2e/game.spec.ts` — пользовательские сценарии через браузер. Поздние игровые состояния задаются через обычное сохранение; тестовых команд в приложении нет.

## Референсы

Игровой цикл вдохновлён [Moon Sweepers](https://store.steampowered.com/app/5335510/Moon_Sweepers/) и официальными [обновлениями разработчиков](https://store.steampowered.com/news/app/5335510). Палитра и образ маскота изучены по [сайту олимпиады PROD](https://prodcontest.com/). Рисунки, интерфейс и реализация созданы для этого проекта; игровые ассеты Moon Sweepers не используются. Это неофициальная фан-игра.

Для обновления экономики изучены [ресурсы и капсулы](https://wikily.gg/moon-sweepers/resources-and-capsules), [станции продажи](https://wikily.gg/moon-sweepers/collector-and-stations) и [производственные машины](https://wikily.gg/moon-sweepers/machines/) оригинала. Оттуда взят принцип: переработка повышает ценность ресурса, а конвейеры доставляют продукцию к отдельной станции продажи. Рецепты, цены построек и время циклов адаптированы для компактной игры.

Для темпа развития дополнительно сопоставлены [ступени инструментов](https://wikily.gg/moon-sweepers/cleaning-tools), [техника](https://wikily.gg/moon-sweepers/vehicles), [роботы](https://wikily.gg/moon-sweepers/joonas-robots) и [производственные цепочки Moon Sweepers](https://wikily.gg/moon-sweepers/production-chains). Это неофициальная справочная база. Оттуда взяты принципы последовательного усиления, дорогой поздней автономии и окупаемости переработки в минутах; цены и длительность адаптированы к нашей карте. Подтверждённого среднего времени открытия техники в оригинале нет.

В текущем расширении использован принцип позднего J.O.O.N.A.S. из [официальных заметок Moon Sweepers 1.0.4](https://steamcommunity.com/app/5335510/?l=schinese): работа вдали от игрока и отправка груза в приёмник без обратного рейса. Размер, цены и лимит флота рассчитаны для нашей однопользовательской игры; точный масштаб мира оригинала не копируется.

Для текущего управления техникой изучены [обсуждения игроков Moon Sweepers о скорости и ширине уборки](https://steamcommunity.com/app/5335510/discussions/0/570427041543954189/). Отсюда взята идея видимой узкой рабочей полосы и медленного рабочего хода. Конкретные характеристики и управление рулём — решения этой игры. Роботы больше не ограничены зонами у приёмников: расширение логистики ускоряет рейсы и увеличивает объём переработки.

Для глобальных роботов и живой карты повторно изучены официальные обновления [Moon Sweepers 1.0.4 и 1.0.5](https://steamcommunity.com/app/5335510?l=german): роботы видны на карте, работают вдали от игрока и отправляют капсулы в приёмники с учётом свободного места. Оригинал поддерживает команды до 16 игроков; размер нашего мира и экономика пересчитаны для более короткой одиночной игры. Точные цены и время открытия роботов оригинала не выдаются за официальные замеры нашей модели.
